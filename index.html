From Figma: select layers, right-click → Copy/Paste as → Copy as SVG, then Ctrl+V here. A normal Ctrl+C in Figma copies Figma's own format, which other apps can't read.

Filled shapes: start each stroke on the end of the last one (a ring shows when it will join) and finish where you began. Then tick Fill.

Reference image: copy any image or take a screenshot (Win+Shift+S), then Ctrl+V here. From Figma, use Copy as PNG (Shift+Ctrl+C).

To Figma: select here, Ctrl+C, then Ctrl+V in Figma. It arrives as editable vectors.

Tablet shows as “Mouse”? Turn on Windows Ink in your tablet driver settings. Browsers only get pen pressure through it.
